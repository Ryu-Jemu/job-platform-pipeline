# CareerRadar 디자인

[CareerRadar](../web/index.html)는 채용 공고의 구성과 원천을 탐색하는 밝은 테마의 정적 화면이다. 관측 시각·규모·범위 설명을 먼저 보여주고 검색 조건과 공고 목록으로 이어진다. 공고 통합 목록, 관측 요약, 수집 상태를 탐색 메뉴로 전환한다.

## 색상과 레이아웃

| 토큰 | 값 | 용도 |
|---|---|---|
| brand | `#6340cf` | 주요 행동과 선택 상태 |
| brand-soft | `#f1edff` | 선택 배경 |
| ink | `#202631` | 제목과 공고명 |
| muted | `#637083` | 조건과 설명 |
| page / surface | `#f7f8fb` / `#ffffff` | 페이지와 카드 |
| border | `#e5e8ef` | 구성요소 경계 |
| success | `#176d55` | 전수 관측 기준 열림 |

8px 간격을 기본으로 입력·버튼은 8px, 카드는 12px 모서리를 사용한다. 데스크톱은 사이드바와 테이블, 모바일은 상단 탐색과 읽기 순서에 맞춘 공고 카드로 구성한다. 운영체제 한국어 글꼴을 사용하며 CSS·JavaScript·데이터를 HTML에 내장해 외부 CDN 없이 동작한다.

## 공고 탐색 기능

- 검색은 회사·공고명·기술을 포함하며 여러 검색어는 AND 조건으로 적용한다.
- 직무, 원천, 지역, 경력, 마감 조건, 관측 상태, 기술 키워드와 저장 공고로 필터링한다.
- 최근 관측·게시일·마감일·회사명·원천 수로 정렬하고 페이지당 20/50/100개를 선택한다.
- 통합 공고마다 연결된 원천 링크를 모두 제공하며 기술 키워드는 펼쳐서 확인한다.
- 저장 공고 ID는 브라우저 localStorage에 보관한다. 저장소를 사용할 수 없으면 현재 페이지에서만 유지한다.
- 전체 통합 공고, 검색 결과, 전체 원천 공고를 CSV로 내려받는다. UTF-8 BOM과 인용부호 처리, 수식 이스케이프를 적용한다.
- 빈 결과에는 필터 초기화 버튼을 제공한다.

관측 요약 차트는 전체 내장 자료를 기준으로 하며 검색 필터와 별도로 표시한다. 기술 필터·차트에는 기술 키워드를 사용하고 역량 키워드는 CSV의 별도 항목으로 보존한다.

## 표시하는 데이터의 의미

지원 조건은 통합 공고의 대표 원천에서 선택한 값이며 미확인 값은 그대로 표시한다. 지역 필터는 대표 원천의 시·도 값을 사용하고 공고 행에는 수집한 지역 원문을 보여준다.

열림 상태는 원천의 마지막 완료 전수 스캔에 따른 관측이다. 현재 지원 가능 여부를 보증하지 않으며 완료 전수 시각을 함께 표시한다. 부분 관측과 수집 시작 전 공백은 화면에 설명한다. 키워드 미검출은 요구 기술이 없다는 뜻이 아니고 중복 통합은 후보 판정이므로 원천 링크로 확인할 수 있다.

## 접근성과 실행

입력 이름, skip link, 키보드 포커스, 현재 탐색·페이지 표시, 저장·상세 필터 상태와 검색 결과 안내를 제공한다. 상태는 색상과 문구로 함께 전달한다. 기술 펼치기는 native details를 사용하고 reduced-motion 설정을 따른다.

```sh
python scripts/build_web.py
python -m http.server 8765 --bind 127.0.0.1
```

프로젝트 루트에서 실행한 뒤 `http://127.0.0.1:8765/web/`를 연다. [HTML 템플릿](../web/template.html), [스타일](../web/styles.css), [화면 동작](../web/app.js)을 수정한 경우 웹 빌드를 다시 실행한다. HTML 파일을 직접 열어도 검색·필터·페이지·CSV 다운로드가 동작한다.
